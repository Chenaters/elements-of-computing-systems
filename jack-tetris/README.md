# Tetris in Jack

Jack project with Main, TetrisGame, Board, Block and Shape classes.

From the collection root:

```sh
python jack-coroutines/JackCompiler.py jack-tetris
```

Load the generated VM directory in the Nand2Tetris VM emulator, with its Jack
OS support. Inspect TetrisGame.jack for controls. Compilation is checked during
publication; interactive gameplay is not retested or claimed here.
