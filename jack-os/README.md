# Jack OS coursework

Coursework implementations of the supplied Array, Keyboard, Math, Memory,
Output, Screen, String and Sys interfaces. Original Nand2Tetris headers and
provided class scaffolding, including output font data, are retained.

```sh
python ../jack-coroutines/JackCompiler.py .
```

Compilation checks are not a full OS behavioral test. The bundled official
course tool/test distribution is excluded; obtain it independently for runtime
validation against the original assignment fixtures.
