# Source and attribution notes

Original student work is presented in the context of Elements of Computing
Systems coursework, using the Nand2Tetris Jack/Hack languages and supplied class
interfaces. Louis Chen identifies the yield addition as his own capstone work.
The broader compiler builds on his preceding class compiler project and course
scaffolding; this collection does not claim invention of Jack, Hack, or the
baseline course materials.

The Square compatibility program is a supplied Nand2Tetris example. Its original
headers are retained. The coroutine test folders come from the original capstone
folder. New automated checks and a limited VM execution harness were added for
publication; they are distinguished from the original course code.

The Jack OS class interfaces, font data and original notices are preserved.
FPGA examples contain board maps and course/template helpers; original headers
remain intact. No blanket open-source license is assigned to supplied material.

The downloaded Nand2Tetris tool distribution, unchanged empty HDL templates,
course handouts, compiled binaries, .git histories, generated VM/XML, macOS
metadata, build products and archives are not published. Source folders remain
unchanged. A private source-hash manifest is kept outside this repository.
